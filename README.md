# Recuperación de Desarrollo de Aplicaciones.

Bienvenido a la evaluación de recuperación para pendientes de aprobación de **Desarrollo de Aplicaciones**. Este proyecto consiste en dos partes, un backend y un frontend, que son los trabajados durante el examen.

Su trabajo será agregar funcionalidad sobre este proyecto, lo que incluye:

1. Que las formas alternativas para cada digimon puedan ser muchas, y no solo una.
Los endpoints de creacion y edición deberían actuar de forma acorde.

2. Que la interfaz muestre varios selects, uno por cada forma alternativa, y la posiblidad de agregar nuevos o qutar existentes.

3. Al editar o crear, si se le agrega una forma alternativa a un digimon, la forma alternativa debe tener el digimon editado o creado como su alternativa también (Dejando la relación hacia ambos lados, de manera consistente).

4. Agregar campos de control, createdAt, updatedAt, como timestamps para control.

5. Agregar la posibilidad de "soft delete" (desde una variable de entorno en el .env del back). Al hacer soft delete, en lugar de borrar completamente el elemento, solo se marca como deletedAt con el timestamp actual. Ojo, los listados siempre deben dar elementos no borrados.

Al agregar toda la funcionalidad, se deberá subir a un repositorio en github, y enviar la dirección a los docentes de la materia para su evaluación. Posteriormente, en el siguiente llamado a examen, deberá inscribirse para que se le pueda pasar la nota al acta.

La fecha límite de entrega para las funcionalidades es el 31 de Agosto.
